How I take a ticket to production with AI agents

I wrote this workflow down as an open source Claude Code plugin, spring-agentic-workflow. Agents do the reading, the planning, the coding and the first reviews. The developer makes every decision that matters.

  1. Understand the requirement against the existing code and constraints
  2. Functional questions the developer answers and approves
  3. Technical plan from the ADRs, one decision at a time with the developer
  4. Orchestration the agents the ticket needs, in proportion to its size
  5. Go the developer starts the implementation
  6. Implementation agents work in parallel, each on its own files
  7. Quality gates tests, JaCoCo coverage, Sonar, architecture rules
  8. AI reviews every business rule proved by a test, past review comments checked
  9. Human review the developer decides to merge

Green steps wait for the developer. The plugin blocks code changes until the plan is approved.
